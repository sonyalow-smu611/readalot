# Card
Pixel card on `surface`: square, a 2px `outline` border and the hard `shadow-card`; used for the Currently Reading card, reviews, quotes and reader rows. Titles in Arial bold.

16px padding. In the app: Bootstrap's `.card` and `.modal-content` get it from `client/src/styles/pixel-surfaces.css`; a component's own card uses `--px-border` and `--px-shadow`.
