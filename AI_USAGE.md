# AI Usage Log

The course allows AI for lower-order tasks: boilerplate, layout/theme ideas, mock data and
explaining errors. It does **not** allow AI to write main business logic, backend endpoints or
critical frontend interactivity. This file records what AI produced so the team can review and
own it. AI-generated files also carry a short top-of-file comment pointing here.
